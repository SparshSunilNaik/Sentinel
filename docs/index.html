AI agents can move money. Sentinel decides when.

A governance control plane for autonomous financial agents. Before a travel, dispute, benefits or servicing agent refunds, rebooks or waives anything, the request passes five gates, gets a risk score, and is approved, sent to a human, or denied, with the reasons written down.

06 / Run it

Run the real thing

Backend

Python 3.11 or 3.12. The pinned pydantic 2.10 has no wheels for 3.14 yet. The database is created and seeded on first start.

cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000

Swagger docs at localhost:8000/docs.

Frontend

Node 20 or newer. Opens on localhost:3000; sign in with the demo operator from the README.

cd frontend
npm install
npm run dev

Or run start-dev.bat (Windows) or start-dev.sh from the repository root.
